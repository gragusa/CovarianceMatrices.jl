Driscoll-Kraay Estimator

The Driscoll-Kraay estimator provides robust covariance estimation for panel data with both temporal and cross-sectional dependence. It extends HAC estimation to panels: observations may be correlated over time within a unit and, within a time period, across units.

Mathematical Foundation

For a panel of $N$ units observed over $T$ periods, the estimator first sums the moment contributions across units within each period,

\[h_t = \sum_{i=1}^{N} g_{it},\]

and then applies a HAC kernel to the time series $h_1, \dots, h_T$:

\[\hat{\Omega}_{DK} = \hat{\Gamma}_0 + \sum_{j=1}^{T-1} k\!\left(\frac{j}{S_T}\right)\left[\hat{\Gamma}_j + \hat{\Gamma}_j'\right], \qquad \hat{\Gamma}_j = \frac{1}{n}\sum_{t=j+1}^{T} h_t h_{t-j}',\]

where $n$ is the number of observations. aVar(dk, X) returns $\hat{\Omega}_{DK}$: dividing by $n$ rather than $T$ puts it on the same per-observation scale as every other estimator, so the sandwich vcov is the same as for them. The moments are demeaned before the period sums are formed (unless demean = false), and periods are ordered by sorting the time identifiers.

Summing over units within a period leaves the cross-sectional correlation unrestricted, so the estimator is robust to arbitrary spatial dependence at each date. Only a single (temporal) kernel and bandwidth are needed.

Core Type

CovarianceMatrices.DriscollKraay — Type
DriscollKraay{K, D, I} <: Correlated

Driscoll-Kraay estimator for panel data with cross-sectional and temporal dependence.

The moments of all units observed in the same period are summed, and the HAC kernel K is applied to the resulting series of period sums. Any correlation across units within a period is absorbed by the sum, and the kernel accounts for serial correlation across periods. The estimator is consistent as the number of periods grows, irrespective of the number of units.

Constructor

DriscollKraay(K::HAC; tis, iis, correction = :HC0)
DriscollKraay(K::HAC, tis::AbstractVector, iis::AbstractVector; correction = :HC0)
DriscollKraay(K::HAC, tis::Symbol, iis::Symbol; correction = :HC0)

where

  • K::HAC: HAC kernel for temporal dependence (Bartlett, Parzen, etc.)
  • tis: time index of each observation. Periods are ordered by sort(unique(tis)), so the identifiers must sort chronologically (numbers, Dates, or zero-padded strings).
  • iis: unit index of each observation. It does not enter the estimate; it is used to check that each (period, unit) pair occurs at most once.
  • correction: finite-sample correction applied by vcov(k, model) for a RegressionModel; one of :HC0 (none), :HC1 or :sss. See vcov(::DriscollKraay, ::RegressionModel).

Both index arrays are required, must have the same length, and may hold identifiers of any sortable type; the two arrays need not share an element type.

With tis and iis given as Symbols, the estimator names the time and unit columns instead of holding them, as CR1(:firm) does for clusters. A modeling package that owns the data table replaces the names with the indices before any variance is computed; CovarianceMatrices itself throws an ArgumentError if asked to use it.

Mathematical Foundation

With $g_t$ the sum of the moments of the observations in period $t = 1, …, T$ (after demeaning the moments), the estimator computes

\[\hat{S} = \sum_{t=1}^{T} \sum_{s=1}^{T} w\!\left(\frac{t - s}{b}\right) g_t g_s'\]

where $w$ is the kernel of K and $b$ its bandwidth. aVar divides $\hat{S}$ by the number of observations n (with scale = true), the same per-observation scale as every other estimator.

References

  • Driscoll, J.C. and Kraay, A.C. (1998). "Consistent Covariance Matrix Estimation with Spatially Dependent Panel Data". Review of Economics and Statistics, 80(4), 549-560.

Examples

# Basic panel setup
ve = DriscollKraay(Bartlett{Andrews}(), tis=time_ids, iis=unit_ids)

# With fixed bandwidth and the Stata-style small-sample correction
ve = DriscollKraay(Parzen(4), tis=years, iis=countries, correction=:sss)

# Time and unit named by column, for a package that resolves them against its data
ve = DriscollKraay(Bartlett(4), tis=:year, iis=:country)

Usage

The estimator combines a HAC kernel with the panel's time and unit identifiers. The Grunfeld data track investment for ten firms over twenty years; both serial correlation within firms and common shocks across firms are present.

using CovarianceMatrices, GLM, RDatasets, LinearAlgebra

grunfeld = RDatasets.dataset("plm", "Grunfeld")
model = lm(@formula(Inv ~ Value + Capital), grunfeld)

dk = DriscollKraay(Bartlett{Andrews}(), tis=grunfeld.Year, iis=grunfeld.Firm)
stderror(dk, model)

Finite-Sample Corrections

The correction keyword of DriscollKraay selects a finite-sample correction that vcov(dk, model) applies for a RegressionModel, reproducing the scalar type options of R's plm::vcovSCC. With n observations, k coefficients, and T time periods:

correctionFactor $c$Description
:HC0 (default)$1$No correction
:HC1$n/(n-k)$Degrees-of-freedom correction
:sss$\dfrac{n-1}{n-k}\cdot\dfrac{T}{T-1}$Stata-style small-sample correction

The correction needs the number of coefficients, so aVar on a bare moment matrix throws an ArgumentError for an estimator with a correction other than :HC0.

dk_fixed(correction) = DriscollKraay(Bartlett(5), tis=grunfeld.Year, iis=grunfeld.Firm; correction)
DataFrame(
    coef = coefnames(model),
    HC0 = stderror(dk_fixed(:HC0), model),
    HC1 = stderror(dk_fixed(:HC1), model),
    sss = stderror(dk_fixed(:sss), model),
)
