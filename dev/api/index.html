Main Functions

Core Estimation Function

CovarianceMatrices.aVar — Function

Asymptotic Variance Estimators

aVar(k::AbstractAsymptoticVarianceEstimator, m::AbstractMatrix{T}; demean::Bool=true, dims::Int=1, means::Union{Nothing, AbstractArray}=nothing, prewhite::Bool=false, scale::Bool=true, scaleby::Union{Nothing, Real}=nothing, weights=nothing)

The asymptotic variance is the matrix Σ of the asymptotic approximation:

\[\sqrt{n}\Sigma^{-1/2} (\bar{X} - \mu) \xrightarrow{d} N(0, I_p)\]

where X̄ is the sample mean of the observations in m (averaged along dims) and μ is the population mean.

Note

  • The element type of m must be Real.
  • prewhite = true prewhitens the matrix with a VAR(1) model. It applies to HAC, EWC and MomentSmoother estimators, and to DriscollKraay, which prewhitens the series of period sums; other estimators do not prewhiten and throw an ArgumentError when it is requested.
  • HR1–HR5/HC1–HC5 and CR1–CR3 need a fitted model to form their finite-sample corrections, so passing them with a matrix throws an ArgumentError; use HR0 or CR0 on a matrix.
  • scale selects whether the variance is divided by the number of observations.
  • scaleby divides the variance by an explicit positive divisor instead, which is convenient for a degrees-of-freedom correction. It takes precedence over scale.
  • scale = true produces the same per-observation scale for every estimator. VARHAC estimates the spectral density at frequency zero, which already carries that scaling, so scale = false multiplies it by the number of observations rather than leaving it untouched.
  • weights gives the per-column weights of the data-driven bandwidth selection of a HAC kernel with Andrews or NeweyWest bandwidth, alone or inside DriscollKraay: one weight per column of m. By default they are bandwidthweights(k, m), which gives a constant column weight 0. A package that forms the moment matrix of a regression passes bandwidthweights(k, X) of the design matrix X, so the intercept gets weight 0 although its moment column is not constant. Other estimators ignore weights.
source
aVar(estimator, model::RegressionModel; kwargs...)

Compute the asymptotic variance matrix for the parameters of a RegressionModel.

This is the generic implementation that works with any model implementing the RegressionModel protocol.

For Uncorrelated() the result is the meat of the iid variance, s² · inv(bread(model)) divided by n, with s² = RSS / n (see vcov); n · bread · aVar · bread then equals vcov(Uncorrelated(), model; dofadjust = false). demean and prewhite do not apply and throw an ArgumentError when set.

source

The Result Type

aVar and vcov return a CovarianceMatrix: the estimate together with the estimator that produced it and any quantities selected along the way. The Returned CovarianceMatrix lists what each estimator stores.

CovarianceMatrices.CovarianceMatrix — Type
CovarianceMatrix{T,M,E,I} <: AbstractMatrix{T}

An estimated covariance matrix together with the estimator that produced it and the quantities selected during estimation.

aVar and vcov return this type. It behaves as an AbstractMatrix: indexing, size, matrix arithmetic, inv, \, diag and factorizations all work through the AbstractMatrix fallbacks. Operations that do not preserve the covariance interpretation — V * V, V + V — return a plain matrix.

The stored matrix is symmetrized at construction: a sandwich estimate is symmetric only to floating-point tolerance, and the symmetrization is applied explicitly rather than hidden behind a Symmetric view that would discard one triangle.

Fields

  • V: the estimate.
  • estimator: the estimator specification, an immutable value.
  • info: a NamedTuple of quantities selected during estimation — bandwidth and kernelweights for HAC kernels, lag orders and information criteria for VARHAC, empty for estimators that select nothing.

Accessors

estimator, bandwidth, kernelweights, information, and parent for the bare matrix.

Examples

V = aVar(Bartlett{Andrews}(), X)
bandwidth(V)        # the bandwidth this estimate was computed with
estimator(V)        # Bartlett{Andrews}()
parent(V)           # the underlying Matrix
V \ b               # works through the AbstractMatrix fallbacks

vcov(form::Information, model::MLikeModel; kwargs...)

Compute variance-covariance matrix for MLE-like models under correct specification assumption.

For MLikeModel + Information:

  • If hessian_objective available: V = inv(H) where H is the Hessian
  • Otherwise: V = inv(G) where G is the cross_score matrix

No variance estimator is involved: the result depends only on the model.

Arguments

  • form::Information: Information form (assumes correct specification)
  • model::MLikeModel: Maximum likelihood model

Keyword Arguments

  • cond_atol::Union{Nothing,Real}=nothing: Absolute tolerance for pseudo-inverse
  • cond_rtol::Union{Nothing,Real}=nothing: Relative tolerance for pseudo-inverse
  • debug::Bool=false: Print detailed debug information
  • check::Bool=true: Perform dimension and compatibility checks
  • warn::Bool=true: Issue warnings for potential issues

Returns

  • CovarianceMatrix: Variance-covariance matrix (Fisher Information inverse); estimator returns form

vcov(estimator, model; dofadjust=true, kwargs...)

Compute the sandwich variance-covariance matrix for a RegressionModel.

For Uncorrelated() the result is the iid (non-robust) variance s² · bread(model) instead of a sandwich. For least squares s² = RSS / (n - K), with n rows and K estimable coefficients, so the result equals R's vcov(lm(...)); with weights, RSS is the weighted sum of squares. For a GLM the result is the dispersion times inv(X'WX), which equals R's vcov(glm(...)); the dispersion is the Pearson statistic divided by n - K for families that estimate one, and 1 for families with a fixed dispersion (Binomial, Bernoulli, Poisson). dofadjust = false divides by n instead of n - K; no other keyword applies. Unweighted, the result is also GLM.jl's vcov; with weights, GLM.jl divides by sum(weights) - K instead of n - K.

source
vcov(k::DriscollKraay, model::RegressionModel; dofadjust = true)

Driscoll-Kraay variance-covariance matrix for a RegressionModel.

With bread B = (X'X)^-1 and A = aVar(k, model), the sandwich is V = c · n · B · A · B: the generic sandwich times the finite-sample factor c selected by the correction of k (n observations, p estimable coefficients, T time periods). The options reproduce the scalar type options of plm::vcovSCC:

  • :HC0 (default): c = 1, no correction.
  • :HC1: c = n / (n - p).
  • :sss: c = (n - 1) / (n - p) · T / (T - 1), the Stata-style small-sample correction.

dofadjust = false leaves out c. The leverage-based :HC2/:HC3/:HC4 options of plm::vcovSCC are not supported. The correction is set only on the estimator; vcov throws an ArgumentError if it is given a type keyword.

source

Bandwidth Selection

optimalbw is the single entry point for bandwidth selection. HAC kernels select from the moment matrix; moment smoothers follow a rate rule in its number of rows. Every method takes the moment matrix.

CovarianceMatrices.optimalbw — Function
optimalbw(k::HAC{Union{Andrews,NeweyWest}}, m::AbstractMatrix;
          demean=false, dims=1, means=nothing, prewhite=false)

Calculate the optimal bandwidth for HAC estimation.

Arguments

  • k::HAC: Kernel estimator (Andrews or NeweyWest)
  • m::AbstractMatrix: Data matrix
  • demean::Bool=false: Remove means before bandwidth calculation
  • dims::Int=1: Dimension along which to compute means (if demeaning)
  • means::Union{Nothing,AbstractArray}=nothing: Pre-computed means (optional)
  • prewhite::Bool=false: Apply VAR(1) pre-whitening

Returns

  • Optimal bandwidth value

Methods

  • Andrews (1991): Uses AR(1) approximation with kernel-specific constants
  • Newey-West (1994): Uses lag-window with data-driven bandwidth

References

Newey, W.K. and West, K.D. (1994). Automatic Lag Selection in Covariance Matrix Estimation. Review of Economic Studies, 61(4), 631-653.

Abstract Types

CovarianceMatrices.AbstractAsymptoticVarianceEstimator — Type

AbstractAsymptoticVarianceEstimator

Abstract supertype for all asymptotic variance (covariance) estimators.

This is the root type of the estimator hierarchy in CovarianceMatrices.jl. All robust covariance estimators inherit from this type.

Type Hierarchy

AbstractAsymptoticVarianceEstimator (abstract)
  * Uncorrelated
  * HR (abstract): HR0/HC0, HR1/HC1, HR2/HC2, HR3/HC3, HR4/HC4, HR4m/HC4m, HR5/HC5
  * Correlated (abstract)
      - HAC{G} (abstract): Bartlett, Parzen, QuadraticSpectral, TukeyHanning, Truncated
      - CR (abstract): CR0, CR1, CR2, CR3, Cluster, CachedCR
      - EWC
      - VARHAC
      - DriscollKraay
  * MomentSmoother (abstract): UniformSmoother, TriangularSmoother

Interface

All subtypes implement the core interface:

  • aVar(estimator, X) - compute asymptotic variance from data matrix
  • vcov(estimator, model) - compute variance-covariance matrix from fitted model
  • stderror(estimator, model) - compute standard errors from fitted model
source
CovarianceMatrices.Uncorrelated — Type

Uncorrelated

Estimator for uncorrelated moment conditions (iid errors).

Use this estimator when the moment conditions are uncorrelated across observations, such as in correctly specified MLE or GMM models with iid errors. This provides the appropriate covariance matrix without unnecessary robust corrections.

What it computes depends on the input:

  • On a matrix of moments, aVar(Uncorrelated(), X) is the contemporaneous variance X'X / n, the same as HR0.
  • On a fitted RegressionModel, vcov(Uncorrelated(), model) is the iid variance s² · bread(model). For least squares s² = RSS / (n - K), so the result is the classical σ̂² (X'X)⁻¹, as R's vcov(lm(...)); for a GLM it equals R's vcov(glm(...)). It is not a heteroskedasticity-robust estimator.

Usage

using CovarianceMatrices
# For MLE or GMM with uncorrelated moments
se_uncorr = stderror(Uncorrelated(), model)
vcov_uncorr = vcov(Uncorrelated(), model)

When to use

  • MLikeModel or GMMLikeModel with iid errors
  • Correctly specified models without heteroskedasticity or serial correlation
  • When you want the efficient (non-robust) covariance estimator
source
CovarianceMatrices.Correlated — Type

Correlated

Abstract type for estimators that account for various forms of correlation.

This encompasses all estimators that handle:

  • Serial correlation (HAC estimators)
  • Cluster correlation (CR estimators)
  • Spatial and temporal correlation (DriscollKraay)
  • Other specialized correlation patterns (EWC, VARHAC)

The smoothed-moments estimators (MomentSmoother) also handle serial correlation but are not subtypes of Correlated.

CovarianceMatrices.Cluster — Type

Cluster

Cluster-robust estimator without finite-sample correction. Cluster(g) gives the same result as CR0(g) on a data or moment matrix and on a fitted model.

Given a T × k data or moment matrix and a vector of group identifiers, aVar(Cluster(groups), X) returns the cluster long-run variance

\[\hat{\Omega} = \sum_{g=1}^{G} \hat{u}_g \hat{u}_g', \qquad \hat{u}_g = \sum_{t \in g} \tilde{X}_t,\]

treating observations as correlated within groups and independent across groups. Cluster is the clustering counterpart of Uncorrelated, which equals HC0. For degrees-of-freedom or leverage corrections on a fitted model use CR1, CR2 or CR3.

Usage

using CovarianceMatrices
clusters = [1, 1, 2, 2, 3, 3, 4, 4]
Ω = aVar(Cluster(clusters), X)

# Multi-way clustering
Ω = aVar(Cluster((firm_ids, year_ids)), X)
source
CovarianceMatrices.MomentSmoother — Type
MomentSmoother

Abstract supertype for Smith's smoothed-moments estimators, UniformSmoother and TriangularSmoother. They smooth the moments first and then take outer products, which gives a positive semidefinite HAC estimate.

MomentSmoother is a direct subtype of AbstractAsymptoticVarianceEstimator, not of Correlated.

References

Smith, R. J. (2005). "Automatic positive semidefinite HAC covariance matrix and GMM estimation." Econometric Theory, 21, 158-170.

CovarianceMatrices.Fixed — Type

Fixed

Fixed (user-supplied) bandwidth for HAC estimators.

Fixed(bw::Real)

A HAC kernel with a fixed bandwidth bw has bandwidth type Fixed: the bandwidth is taken as given rather than selected from the data. Bartlett(Fixed(4)) and the shorthand Bartlett(4) construct the same kernel. Use the type parameter to dispatch on fixed-bandwidth kernels via HAC{Fixed}.

bw must be finite and nonnegative; a bandwidth of zero gives the heteroskedasticity-robust (HC0) estimate.

Usage

using CovarianceMatrices
k = Bartlett(Fixed(4))       # Bartlett kernel, fixed bandwidth 4
k == Bartlett(4)            # true
bandwidth(k)                # 4.0
k isa HAC{Fixed}            # true

# Dispatch on fixed-bandwidth kernels
describe(::HAC{Fixed}) = "fixed bandwidth"
describe(::HAC) = "data-driven bandwidth"

See also Andrews and NeweyWest for data-driven bandwidth selection.

CovarianceMatrices.cross_score — Function
cross_score(model) -> AbstractMatrix

Return the cross-product matrix of the moment conditions (also known as the "meat" of the sandwich estimator or the Jacobian matrix of moment conditions).

This is the unscaled cross-product: G = ∑ᵢ gᵢgᵢ' where gᵢ are the moment contributions (or equivalently g'g where g is the moment matrix).

Returns

  • AbstractMatrix: m × m matrix where m is the number of moment conditions.
function cross_score(model)
    g = momentmatrix(model)
    return (g' * g)
end

This default works for most cases. Override only if you have an analytical expression or need custom behavior.

Important: Scaling Convention

The returned matrix should be unscaled - that is, it should be the sum of cross-products, NOT divided by the number of observations.

This convention ensures consistency with the unscaled Hessian and allows the variance computation formulas to work correctly.

Note

For MLE models, this is related to the Fisher Information matrix. For GMM models, this is the "G" matrix in the variance formula.

CovarianceMatrices.jacobian_momentfunction — Function
jacobian_momentfunction(model) -> AbstractMatrix

Return the Jacobian matrix of the moment function with respect to parameters.

This is the matrix of derivatives of the (summed) moment conditions with respect to the parameters: ∂(∑ᵢ gᵢ)/∂θ' where gᵢ are individual moment contributions.

Returns

  • AbstractMatrix: m × k matrix where m is the number of moment conditions and k is the number of parameters.

Important: Scaling Convention

The returned matrix should be unscaled - the derivative of the sum of moments, not the average.

Note

Required for vcov on a GMMLikeModel: both the Information and Misspecified forms use this Jacobian as the G matrix. The fallback returns nothing, and vcov throws an ArgumentError when a GMM model leaves it unimplemented rather than proceeding with a meaningless result. For MLE models it is unused and may be left at the default.

CovarianceMatrices.VcovSpec — Type
VcovSpec{T}

A variance estimator packaged for a modeling package, built by the one-argument vcov(estimator). The source field holds the estimator unchanged.

CovarianceMatrices defines no operation that consumes a VcovSpec. A modeling package that supports the model + vcov(estimator) idiom defines Base.:+(m::MyModel, v::VcovSpec), reads the estimator from v.source, and returns the model with that estimator attached. If the estimator names its clusters by column (CR1(:firm)), the modeling package replaces the names with the group vectors from its data before computing the variance; see the "For Modeling Packages" section of the interface tutorial.

Examples

spec = vcov(CR1(:firm))   # VcovSpec(CR1(:firm))
spec.source               # CR1(:firm)

Public but Not Exported

The names below are part of the API: they are supported and follow the package's compatibility guarantees, but they are not exported, so they must be reached through the module — CovarianceMatrices.nclusters(k). They are declared with public, so Base.ispublic reports them.

AICs, BICs, maxlags, nclusters, order, order_aic and order_bic are the result and estimator accessors documented above. BartlettKernel, ParzenKernel, QuadraticSpectralKernel, TruncatedKernel and TukeyHanningKernel are the kernel struct names; the exported Bartlett, Parzen, QuadraticSpectral, Truncated and TukeyHanning are aliases for them, and these are the names that appear when a kernel is displayed. BandwidthType, LagSelector and LagStrategy are abstract supertypes available for dispatch.

Clustering is the grouping of one clustering dimension; clusters(k) returns those of a cluster estimator, and groups and nclusters read a Clustering. cache and the exported estimator read a CachedCR; CRModelCache is the type of the cache that CachedCR(k, model) builds. timekernel, timeindex, unitindex and correction read a DriscollKraay estimator.

bread, momentresiduals, leverage, mask and numobs are the protocol a RegressionModel implements to work with vcov(k, model). residual_adjustment and bandwidthweights are for packages that form their own moment matrices; see Building Moment Matrices in a Modeling Package. momentmatrix, cross_score, hessian_objective, jacobian_momentfunction and weight_matrix are the protocol an MLikeModel or GMMLikeModel implements; they are documented under Model Interface Functions.

CovarianceMatrices.Clustering — Type
Clustering

Grouping of observations into clusters. Cluster estimators (CR0–CR3, Cluster) store one Clustering per clustering dimension in their g field.

Maps arbitrary cluster identifiers to contiguous integer group codes 1:G, in the order the identifiers are first encountered.

Accessors

  • groups(c): the group code of each observation.
  • nclusters(c): the number of groups G.

Usage

using CovarianceMatrices: Clustering, groups, nclusters

# Single clustering dimension
cl = Clustering([1, 1, 2, 2, 3, 3])
groups(cl)     # [1, 1, 2, 2, 3, 3] - already contiguous
nclusters(cl)  # 3

# Works with any element type
cl = Clustering(["A", "A", "B", "B", "C"])
groups(cl)     # [1, 1, 2, 2, 3]
nclusters(cl)  # 3

# Multi-way clustering
cl = Clustering([1, 1, 2, 2], ["A", "B", "A", "B"])
groups(cl)     # Unique combinations mapped to 1:G
nclusters(cl)  # Number of unique (id1, id2) combinations

CovarianceMatrices.cache — Function
cache(k::CachedCR)

Return the cache of k. Its use is to wrap the same cache with another estimator. Its type is internal, except that a cache built from a model is a CRModelCache. A cache built by CachedCR(k, ncols) depends only on the clusters, so CachedCR(CR0(clusters(k)), cache(k)) computes CR0 on the clusters of k with the same buffers. A cache built by CachedCR(k, model) also holds adjustments for the type of k, and must stay with an estimator of that type.

CovarianceMatrices.CRModelCache — Type
CRModelCache{H}

Cache for cluster-robust variance calculations on a RegressionModel. Built by CachedCR(k, model). Stores the leverage adjustments, which depend only on the model matrix and the cluster structure, not on the residuals. This enables fast repeated variance calculations (e.g., wild bootstrap) where only residuals change between iterations.

The type is public so that a modeling package can dispatch on CachedCR{<:CR, <:CRModelCache}, for example to reject a cache built from a model of another type. Its fields are internal.

Type Parameters

  • H: Type of leverage adjustments (Vector of ClusterLeverage for CR2/CR3, Vector of scalars for CR0/CR1)

Fields

  • grouped_arrays: Precomputed Clusterings for each clustering combination
  • cluster_indices: Precomputed observation indices [combination][cluster] -> obs indices
  • signs: Precomputed signs for inclusion-exclusion formula
  • leverage_adjustments: Precomputed leverage adjustments, one per clustering combination
  • ncols: Number of model coefficients (for validation)
  • nobs: Number of observations (for validation)

Notes

Using this cache makes the variance calculation non-differentiable with AD. For AD compatibility, use the standard non-cached CR estimators.

CovarianceMatrices.bread — Function
bread(model::RegressionModel) -> AbstractMatrix

Return the k × k bread of the sandwich, scaled so that vcov(k, model) = n · bread(model) · aVar(k, model) · bread(model) with n the number of rows of modelmatrix(model). For least squares this is inv(X'X); for a GLM it is inv(X'WX) times the dispersion. Rows and columns of non-estimable coefficients (see mask) are ignored. Required: there is no fallback.

source
CovarianceMatrices.momentresiduals — Function
momentresiduals(model::RegressionModel) -> AbstractVector

Return the per-observation residuals u for which modelmatrix(model) .* u is the matrix of score (moment) contributions. For unweighted least squares these are the ordinary residuals; with weights w they are w .* residuals(model); for a GLM they are the working residuals times the working weights, divided by the dispersion.

The fallback calls StatsAPI.residuals(model), which is correct only for unweighted least squares.

source

leverage(model::RegressionModel) -> AbstractVector

Return the diagonal of the hat matrix, one entry per observation. Needed only by the leverage-based estimators HC2–HC5 (HR2–HR5). The fallback calls StatsAPI.leverage(model).

CovarianceMatrices.mask — Function
mask(model::RegressionModel) -> AbstractVector{Bool}

Return a vector with one entry per coefficient, true for estimable coefficients and false for coefficients dropped because the design is rank deficient. The variance of a dropped coefficient is reported as NaN. The fallback marks every coefficient estimable.

CovarianceMatrices.numobs — Function
numobs(model::RegressionModel) -> Integer

Return the number of observations n of model: the number of rows of its moment matrix, which divides the variance in aVar and enters the finite-sample corrections (n / (n - K) for HR1 and the long-run estimators, (n - 1) / (n - K) for CR1). The fallback is size(modelmatrix(model), 1). A model whose modelmatrix is expensive to form, or whose StatsAPI.nobs counts weighted observations, can define it.

source
CovarianceMatrices.residual_adjustment — Function
residual_adjustment(k::HR, model::RegressionModel) -> Real or AbstractVector
residual_adjustment(k, model::RegressionModel) -> Real

Return the factor a that multiplies the residuals of model before the moments are formed: aVar(k, model) is computed from modelmatrix(model) .* (a .* u) with u = momentresiduals(model). a is a scalar or a vector with one entry per observation.

A package that builds its own moment matrix calls this to apply the finite-sample adjustments of HR1–HR5, and then passes the moments to aVar with HR0, which is the estimator aVar accepts on a matrix:

a = CovarianceMatrices.residual_adjustment(HC3(), model)
M = modelmatrix(model) .* (a .* CovarianceMatrices.momentresiduals(model))
aVar(HC0(), M)

With n = numobs(model), K = length(coef(model)) and h = leverage(model):

  • HR0/HC0: 1.
  • HR1/HC1: √(n / (n - K)).
  • HR2/HC2: 1 ./ √(1 .- h).
  • HR3/HC3: 1 ./ (1 .- h).
  • HR4/HC4, HR4m/HC4m, HR5/HC5: (1 .- h) .^ (-δ / 2) with the exponents δ of Cribari-Neto (2004), Cribari-Neto and da Silva (2011), and Cribari-Neto et al. (2007).
  • HAC kernels, EWC, VARHAC, DriscollKraay and the moment smoothers: 1. Their degrees-of-freedom correction is a factor of vcov, not of the residuals.

The leverage-based adjustments do not modify the vector leverage(model) returns, so a model may return a stored vector. For cluster estimators the return value is internal.

CovarianceMatrices.bandwidthweights — Function
bandwidthweights(k, X::AbstractMatrix) -> Union{Vector, Nothing}

Return the per-column weights that the data-driven bandwidth selection of k uses for the matrix X: 0 for a constant column, which carries no information about serial correlation, and 1 for every other column. Returns nothing for an estimator that selects no bandwidth from the data: a kernel with a fixed bandwidth, or any estimator other than a HAC kernel or a DriscollKraay estimator with one.

aVar(k, M) computes the weights from the moment matrix M itself, unless they are passed as the weights keyword. For a regression, the moment matrix is the design matrix times the residuals, and its intercept column is not constant. A package that builds its own moment matrix passes the weights of the design matrix instead, as vcov(k, model) does:

X = modelmatrix(model)
M = X .* CovarianceMatrices.momentresiduals(model)
aVar(k, M; weights = CovarianceMatrices.bandwidthweights(k, X))

The result records the weights used: see kernelweights.
